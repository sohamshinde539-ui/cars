## **🔍 Troubleshooting:**

### **If file doesn't open:**
1. **Right-click** → "Open with" → Choose browser
2. **Drag file** into browser window
3. **File path:** Should end with `.html`

### **If 3D model doesn't rotate:**
1. Check browser console for errors
2. Try refreshing the page
3. Test in different browser

### **If it's slow:**
1. Close other browser tabs
2. Disable browser extensions
3. Try hardware acceleration
